# Seaborn_Iot_Analysis

## Projet Seaborn:  Analyse de données IoT

Ce projet consiste à réaliser une analyse exploratoire de données IoT à l'aide de Python et principalement de Seaborn.
Les données proviennent de capteurs installés dans plusieurs bâtiments et contiennent notamment la température, l'humidité, la pression, la consommation énergétique et l'état des capteurs.

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
